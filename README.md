## 🧠 Classification Guide

### Implementation

Problems where the main challenge is translating the problem statement directly into code, without requiring a specific algorithmic technique.

### Math

Problems primarily solved using mathematical observations, formulas, arithmetic, number theory, or mathematical properties.

### Strings

Problems involving string manipulation, comparison, character processing, or string-based algorithms.

### Sorting

Problems where sorting is a central part of the solution.

### Greedy

Problems where making a locally optimal choice at each step leads to the globally optimal solution.

### Bit Manipulation

Problems involving bitwise operations such as:

```text
AND (&)
OR  (|)
XOR (^)
NOT (~)
Left Shift (<<)
Right Shift (>>)
```

### Two Pointers

Problems solved by maintaining and moving two indices through an array or string.

### Binary Search

Problems involving binary search over a sorted structure or binary search over the answer space.

### Prefix Sum

Problems where cumulative sums are used to answer range or subarray queries efficiently.

### Dynamic Programming

Problems involving overlapping subproblems, states, transitions, and optimal substructure.

### Graphs

Problems involving vertices, edges, traversal, connectivity, shortest paths, or other graph concepts.

### Data Structures

Problems where structures such as stacks, queues, sets, maps, heaps, or other data structures are central to the solution.

## 📌 How Problems Are Classified

A problem may have multiple Codeforces tags, but each problem in this repository is assigned a **Primary Topic** based on the main idea required to solve it.

For example:

```text
Problem:
Sort → Make optimal choices → Get the answer

Primary Topic: Greedy
Other Concept: Sorting
```

The classification is based on **the idea behind the solution**, not the number of lines of code.

A short solution can still be a Greedy, Binary Search, or Dynamic Programming problem.
